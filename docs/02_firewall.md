# Windows Defender ファイアウォール解説

## ファイアウォールとは

ファイアウォールは、コンピュータへの**不正なアクセスを防ぐセキュリティ機能**です。
ネットワークと外部の間に置かれた"壁"のような役割をします。

## ファイアウォールの役割

### 1. 不正アクセスの防止
- 許可されていないポートへのアクセスをブロック
- マルウェアの通信を遮断
- 外部からの攻撃を検出・防止

### 2. 出力トラフィックの制御
- アプリケーションの不正な通信を検出
- 感染したプログラムの通信を遮断

### 3. ログ記録
- アクセス試行の記録
- セキュリティインシデントの調査に活用

## Windows Defender ファイアウォール

### 概要
Windows 10/11に標準装備されたファイアウォール機能です。
シンプルながら、基本的なセキュリティ要件を満たします。

### 起動確認方法

#### 方法1: コントロールパネル
```
1. Windows キーを押す
2. "ファイアウォール"と入力
3. "Windows Defender ファイアウォール"をクリック
```

#### 方法2: Windowsセキュリティ
```
1. Windows キーを押す
2. "セキュリティ"と入力
3. "Windowsセキュリティ"をクリック
4. 「ファイアウォールとネットワーク保護」をクリック
```

### 設定画面

#### 保護されているプロファイル
- **ドメイン**: 企業ネットワークに接続時
- **プライベート**: 自宅・信頼できるネットワークに接続時
- **パブリック**: 公開ネットワーク（カフェ等）に接続時

各プロファイルで個別に設定可能です。

## ポート開放の設定方法

### 方法1: GUIから設定（推奨）

#### ステップ1: ファイアウォール設定を開く
```
1. コントロールパネルを開く
2. 「Windows Defender ファイアウォール」をクリック
3. 左側の"アプリケーションまたは機能をファイアウォール経由で許可"をクリック
```

#### ステップ2: ルールを追加
```
1. "別のアプリケーションを許可"をクリック
2. アプリケーションを選択または参照
3. "プライベート"と"パブリック"のチェックボックスを選択
4. "追加"をクリック
```

### 方法2: コマンドプロンプトで設定

#### コマンドの基本形式
```bash
netsh advfirewall firewall add rule name="ルール名" \
dir=in action=allow protocol=tcp localport=ポート番号
```

#### 実例: ポート8080を開放
```bash
netsh advfirewall firewall add rule name="Port 8080" \
dir=in action=allow protocol=tcp localport=8080
```

#### 実例: ポート3306（MySQL）を開放
```bash
netsh advfirewall firewall add rule name="MySQL" \
dir=in action=allow protocol=tcp localport=3306
```

#### ルールを削除する場合
```bash
netsh advfirewall firewall delete rule name="ルール名"
```

### 方法3: セキュリティの詳細設定から

```
1. "セキュリティが強化されたWindows Defender ファイアウォール"を開く
2. 左側の"受信の規則"をクリック
3. 右側の"新しい規則..."をクリック
4. "ポート"を選択 → "次へ"
5. 「TCP」を選択し、ポート番号を入力 → "次へ"
6. "接続を許可する"を選択 → "次へ"
7. プロファイルを選択 → "次へ"
8. ルール名を入力 → "完了"
```

## トラブルシューティング

### Q: コマンドが実行できない
**A:** コマンドプロンプトを**管理者として実行**してください

### Q: ファイアウォール設定が反映されない
**A:** 設定反映に数秒かかります。以下を確認してください：
- ファイアウォールが有効になっているか
- ルール名に誤りがないか
- PCの再起動が必要な場合もあります

### Q: アプリケーションが動作しない
**A:** ファイアウォール設定確認手順：
```
1. アプリケーションが使用するポートを確認
2. ファイアウォール設定で許可されているか確認
3. 必要に応じてルールを追加
```

## ベストプラクティス

### ポート開放時
1. **必要最小限に絞る**
   - 使用するポートのみ開放
   - 不要なプロトコルは許可しない

2. **明確な命名規則**
   - ルール名でポート用途を明確に
   - 後で確認しやすくする

3. **定期的な確認**
   - 月に1回は開放ポート一覧を確認
   - 不要なルールは削除

4. **ログの確認**
   - ブロックされた接続ログを確認
   - 異常なアクセスパターンを検出

## まとめ

- ファイアウォールはセキュリティの最初の防線
- Windows Defenderは基本的な保護に十分
- ポート開放は必要最小限に
- 設定変更後は動作確認を忘れずに
