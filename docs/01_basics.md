# ポートの基礎知識

## ポートとは

### 概要
ポートは、コンピュータがネットワーク通信を行う際の**"窓口"**です。
IPアドレスがコンピュータの住所なら、ポートはそのコンピュータ内の特定のアプリケーションへの玄関番号です。

### ポート番号の範囲
- **0 ～ 65,535**: すべてのポート番号
- **0 ～ 1,023**: 予約済みポート（よく使われるサービス用）
- **1,024 ～ 49,151**: 登録済みポート
- **49,152 ～ 65,535**: 動的/プライベートポート

## よく使われるポート番号

| ポート番号 | プロトコル | 用途 |
|----------|---------|------|
| 21 | FTP | ファイル転送 |
| 22 | SSH | リモートアクセス |
| 80 | HTTP | Webサーバー |
| 443 | HTTPS | 安全なWebサーバー |
| 3306 | MySQL | データベース |
| 5432 | PostgreSQL | データベース |
| 8080 | HTTP (代替) | Webサーバー |
| 3389 | RDP | リモートデスクトップ |
| 5900 | VNC | リモート画面共有 |

## プロトコルの種類

### TCP (Transmission Control Protocol)
- **接続型**: 通信前に接続を確立
- **信頼性**: データ到達を保証
- 用途: Webサーバー、メール、FTP等

### UDP (User Datagram Protocol)
- **非接続型**: 接続を確立しない
- **高速**: TCPより速い
- 用途: DNS、ゲーム、ビデオストリーミング等

## ポートの状態

### 開放（Open）
- ポートがリッスンしている
- 外部からアクセス可能
- アプリケーションが応答する

### 閉鎖（Closed）
- ポートがリッスンしていない
- アプリケーションが動作していない
- RST応答が返される

### フィルター済み（Filtered）
- ファイアウォールでブロックされている
- RST応答が返されない
- 状態が不明

## ポート開放の流れ

```
アプリケーション起動
        ↓
  ポート開放設定
        ↓
  ファイアウォール許可
        ↓
 外部からアクセス可能
```

## ポート開放が必要な場面

1. **ゲームのマルチプレイ機能**
   - オンラインマルチプレイをするときポート開放が必要な場合がある

2. **リモートアクセス**
   - 自宅のPCに外出先からアクセスしたい

3. **Webサーバー公開**
   - 自作サイトをインターネットに公開したい

4. **ファイル共有**
   - 外部ユーザーとファイルを共有したい

5. **開発・テスト**
   - ローカル開発環境にアクセスしたい

## セキュリティに関する注意

### リスク
- 不要なポート開放は攻撃の窓口になる
- マルウェア感染のリスクが高まる
- 不正アクセスの可能性

### 対策
1. **最小権限の原則**
   - 必要なポートのみ開放
   - 不要になったら速やかにクローズ

2. **定期的な確認**
   - 開放ポート一覧の確認
   - 不要なサービスの停止

3. **強力な認証**
   - 複雑なパスワード設定
   - パスフレーズの定期変更

4. **ログ監視**
   - アクセスログの定期確認
   - 異常なアクセスの検出

## まとめ

- ポートは通信の窓口
- 必要に応じて開放・クローズする
- セキュリティを意識した運用が重要
- 定期的な確認と管理が必須
